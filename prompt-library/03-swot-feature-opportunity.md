# Prompt 03: SWOT Analysis for Feature Opportunity

**Session:** 05 — Competitor Research and Analysis
**Source:** Class 5 - Competitor Research and Feature Analysis_.docx

## What it does

Evaluates whether a specific feature opportunity (found through competitor analysis) is worth pursuing. Generates a SWOT analysis scoped to that one feature decision.

## Required input

| Parameter | Description | Example |
|-----------|-------------|---------|
| Company name | Who would build it | "Blinkit" |
| Feature description | The opportunity from competitor analysis | "Scheduled/bulk ordering flow" |

## Use cases

- Session 06 assignment: SWOT on one named feature
- Go/no-go decision on a competitor-inspired feature
- Building the case for leadership approval
- Chains directly from Prompt 02 (Competitor Feature Analysis)

## The prompt

```
[After identifying a feature from the competitor analysis]

Let me assume that [COMPANY] wants to make this feature available in their product. Can you give me a detailed SWOT Analysis for [COMPANY] which will help me understand if I should pursue this opportunity. Give the SWOT in an image format.
```

## How to adapt

Replace `[COMPANY]` with your company name and describe the specific feature opportunity you identified from the competitor analysis. This prompt works best as a follow-up to Prompt 02 in the same conversation, so the AI already has context about your competitive landscape.
