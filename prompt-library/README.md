# Prompt Library

8 ready-to-use AI prompts from the Masai PM course (Misfit Technology framework). One more was shared via Zoom chat and isn't captured here.

Every prompt follows the same structure: role assignment, minimal input questions, structured output, concise deliverable.

## Quick reference

| # | Prompt | Session | Use case | Required input |
|---|--------|---------|----------|----------------|
| 1 | [User Research Guide](01-user-research-guide.md) | S03 | Generate interview/survey questions with bias detection | Product name + description |
| 2 | [Competitor Feature Analysis](02-competitor-feature-analysis.md) | S05 | Full competitor teardown with feature matrix | Company name + product type |
| 3 | [SWOT for Feature Opportunity](03-swot-feature-opportunity.md) | S05 | Evaluate whether to pursue a competitor's feature | Company + feature name |
| 4 | [TAM SAM SOM Sizing](04-tam-sam-som.md) | S05 | Interactive market sizing with sources | Product + industry + geography |
| 5 | [User Persona Generator](05-user-persona.md) | S04 | Visual persona card with JSON data block | Product name + 1-liner |
| 6 | [User Journey Map](06-user-journey-map.md) | S04 | 5-stage journey map with HMW opportunities | Product + goal + problem + persona |
| 7 | [Find Beta Programs](07-find-beta-programs.md) | S06 | Discover beta testing programs to join | Industry + region |
| 8 | [Stitch Screen Refinement](08-stitch-screen-refinement.md) | S08 | Convert rough screens into a Google Stitch prompt | Hypothesis + screen descriptions |

## How to use

1. Copy the prompt into Claude, ChatGPT, or Gemini
2. Answer the AI's clarifying questions with your product details
3. Iterate on the output — the first pass is a draft, not a deliverable
4. Cross-check AI-generated data against real sources before using it in your portfolio
