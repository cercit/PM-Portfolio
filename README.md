# PM Course Portfolio

Practice assignments from the Masai Product Management certification (Jul–Aug 2026, 10 sessions). Each folder contains one session's deliverables.

## Sessions

| # | Topic | Assignments |
|---|-------|-------------|
| 01 | PM with AI | Vendor map, AI layer classification, moat test, context experiment |
| 02 | Day in the Life | Day-in-the-life one-pager, defensive features, daily flow mapping |
| 03 | Research Methods | Question writing, qual/quant grid, secondary research deep-dive |
| 04 | User Interviews | Interview questions, journey mapping, bias teardown, AI vs human interview |
| 05 | Personas and Journeys | Pain points, app-store review clustering, persona building, journey map |
| 06 | Competitor Research | Feature matrix, SWOT, TAM/SAM/SOM, pricing row, Voice of User report |
| 07 | MVP | Product audit, riskiest assumption, MVP scoping, concierge design |
| 08 | Design Thinking + AI | Constraint test, HITL flow, prototype design, two-model council |
| 09 | Wireframing and Figma | Paper wireframes, app flow, Figma prototype |
| 10 | Usability Testing | Hypotheses, test plan, moderated sessions, findings report |

## Structure

```
session-01-pm-with-ai/
  README.md          <- assignment brief + deliverable
  assets/            <- screenshots, exports, supporting files
session-02-day-in-life/
  ...
```

Each session README lists the assignments with checkboxes so progress is trackable.
