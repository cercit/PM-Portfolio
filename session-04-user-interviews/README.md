# Session 04 — User Interviews

## Assignments

- [ ] **Ambulance case questions** — Write six questions: past tense, what + how, no feature named, no "why".
- [ ] **Journey mapping** — Write your own journey for one daily app: five time-stamped steps, four use-case types, one cross-touchpoint pattern.
- [ ] **Research prompt** — Run the research prompt end to end, then edit its output against the pre-flight checklist.
- [ ] **Bias teardown** — Ten questions found in the wild, name the bias in each, rewrite it.
- [ ] **AI vs human interview** — Interview an AI in character, then a real person. Compare hesitations, tangents and workarounds.
