# Session 06 — Competitor Research and Analysis

## Assignments

- [ ] **Feature matrix + SWOT + sizing** — Run all three prompts on one product: matrix with 8 rows and 4 rivals, SWOT on one feature, TAM/SAM/SOM.
- [ ] **Hand-verify the matrix** — Open three competitor apps and six months of release notes, list three corrections with sources.
- [ ] **Pricing row** — Build the pricing row: entry price, paid tiers, free tier, bundles. Include one far costlier rival.
- [ ] **Voice of User report** — Mine 40 app-store reviews plus one forum thread: top 5 issues, top 3 requests.
- [ ] **Quarterly filing predictions** — Read one competitor's latest quarterly filing and write five dated predictions of what it ships next.
