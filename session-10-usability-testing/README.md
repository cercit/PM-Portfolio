# Session 10 — Usability Testing

## Assignments

- [ ] **Hypotheses** — Write three hypotheses (too narrow, right altitude, too elaborate) for a product that doesn't exist. Add a time bound.
- [ ] **Screens as user actions** — Convert your hypothesis into five screens as user actions. Hand them to someone: can they describe the app back?
- [ ] **Stitch prototype** — Build a prototype in Stitch. Find and fix four specific defects before showing it.
- [ ] **Test plan** — Fill in the one-page test plan: objective, screener, three goal-phrased tasks (no task names a button).
- [ ] **Moderated sessions** — Run three moderated sessions. Use only the approved replies. Count your assists.
- [ ] **Findings report** — Write findings as number + behaviour + cause, rated P0-P3, clustered by Navigation / Comprehension / Interaction.
