# Session 01 — PM with AI

## Assignments

- [ ] **Vendor map** — For each firm, list text, image, video, audio and code models plus platforms.
- [ ] **AI layer classification** — Pick 10 AI features you use daily; classify each by layer with a one-line justification.
- [ ] **Task vs foundation split** — Split one product into task-based and foundation steps; add volume estimates per step.
- [ ] **Kill your own moat** — Try to reproduce your product's differentiator in 15 minutes of prompting.
- [ ] **Context experiment** — Same question, no context vs three sentences of context vs rephrased context. Save all three answers.
