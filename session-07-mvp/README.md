# Session 07 — MVP

## Assignments

- [ ] **Product audit** — Audit eight products you use: first trigger, why you stay, convenience or comfort by the disappearance test.
- [ ] **Riskiest assumption** — Write the single riskiest assumption behind your course idea, in one sentence.
- [ ] **MVP scoping** — Pick one MVP type, list three features you are deliberately not building, and set a numeric pass bar.
- [ ] **Concierge design** — Design a concierge version you could run free this week: who, where they gather, what you do by hand.
- [ ] **Beta programme** — Join a beta programme, read the data terms before accepting, use it for two weeks.
