# Session 05 — Personas, Empathy Maps and Journeys

## Assignments

- [ ] **Pain points** — Write ten pain points for one daily app with the template; grade each against the three tests.
- [ ] **App-store review clustering** — Take 20 real app-store reviews, cluster into five buckets, converge to one want.
- [ ] **Persona building** — Build primary and secondary personas; correct every AI-invented field with real evidence.
- [ ] **Journey map** — Map five stages with actions, feelings, pains, HMW opportunities and one metric each.
- [ ] **Pain point sprint** — Five days, five products, 15 pain points daily. Track your hit rate.
