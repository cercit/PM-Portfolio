# Session 08 — Design Thinking + AI

## Assignments

- [ ] **Constraint test** — Kill your own idea with the constraint test: list every process change you impose, then remove at least two.
- [ ] **HITL flow** — Map an end-to-end product flow with at least three human-in-the-loop checkpoints.
- [ ] **Prototype design** — Design the prototype, not the product: isolate the make-or-break module, write its failure branch.
- [ ] **Two-model council** — Write a rubric, send identical input to two models, reconcile with a third.
