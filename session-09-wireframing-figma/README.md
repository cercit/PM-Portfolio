# Session 09 — Wireframing and Figma

## Assignments

- [ ] **Paper wireframes** — Ten-minute timer: four chocolate screens on paper, then four more with a different opening.
- [ ] **App flow from memory** — Write a weekly app's main flow from memory, then walk it and correct the list.
- [ ] **Figma frames** — Build three named iPhone frames: Scan QR, Select Bank, Payment Completion.
- [ ] **Figma prototype** — Connect them in the Prototype tab, add one back link, hit Play.
